# 安装与快速上手

## 安装要求

| 项目 | 要求 |
|---|---|
| Minecraft | 1.21.1 |
| Java | 21 或更高 |
| Cobblemon | **1.8.0 及以上、1.9 以下** |

### Fabric 平台

| 依赖 | 要求 |
|---|---|
| Fabric Loader | 0.19.1 或更高 |
| Fabric API | 必需 |
| Fabric Language Kotlin | 必需 |

### NeoForge 平台

| 依赖 | 要求 |
|---|---|
| NeoForge | 21.1.215 或更高 |
| Kotlin for Forge | 5.12.0 或更高 |
| Cobblemon（NeoForge 版） | 必需 |

> NeoForge 平台**不需要** Architectury API。

### 可选依赖

| 模组 | 作用 |
|---|---|
| Cobblemon Economy | ~~虚拟货币（仅 Fabric 平台有）~~ ⚠ **暂时不受支持**：与 Cobblemon 1.8 不兼容，装了会导致选初始精灵时崩服 |
| CobbleDollars | 虚拟货币 |
| Impactor | 虚拟货币 |
| Cobblemon Smartphone | 从手机应用进入市场 |

不装任何虚拟货币模组时，市场使用**物品货币**（默认钻石）。四种货币模式的优先级与配置见 [货币系统](/currency)。

## 安装步骤

1. **下载对应平台的 jar** —— Fabric 服务端装 Fabric 版，NeoForge 服务端装 NeoForge 版
2. **放进 `mods` 目录** —— **服务端和客户端都要装**（市场界面在客户端渲染）
   - 单人游戏：`.minecraft/mods/`
   - 专用服务器：`<服务器目录>/mods/`
3. **启动** —— 首次启动会生成配置文件 `config/cobblemarket.json`

> 版本不匹配（如把 Fabric 版装到 NeoForge 服务端）会导致模组不加载，请确认下载的是对应平台的 jar。

## 快速上手

1. 按 `K`、输入 `/market gui`，或从 Cobblemon Smartphone 应用进入市场
2. **上架**：在精灵市场/物品市场里选择要卖的精灵或物品，设定价格后确认（会收取手续费）
3. **购买**：浏览列表，点击条目购买；精灵直接进队伍或 PC，物品进背包
4. **查看收益**：「待领取」界面领取卖出所得与过期退回的货物

## 服主首次配置建议

1. **确认货币模式** —— 见 [货币系统](/currency)；装了虚拟货币模组会自动探测，无需手动开启
2. **调整费率与上限** —— 在市场入口的「服务器配置」界面里直接改，无需编辑文件
3. **按需开启可选功能** —— 蛋交易、喵喵银行默认关闭，开启方式见对应文档
4. **改完配置文件** —— 用 `/market reload` 免重启生效（货币相关配置仍需重启）

> 建议开放市场前先自己跑一遍完整的买卖流程，确认费率与货币显示符合预期。
