# 自定义 NPC 商店

把服务器上**你自己的 NPC**（Easy NPC / Impactor / 自己生成的自定义实体 / 原版村民…**任意实体**）绑定成商店 —— 玩家**右键那个 NPC 就打开这家店**。模组不会另外生成商店 NPC，用的就是你放好的那一个，带自定义皮肤 / 模型的也照常。界面与 RP 商城同一张背景、标题换成店名；每家店的商品、库存、价格、开关互相独立，结算货币可选**主货币**或 **RP**。

## 建店与绑定

- **推荐在管理员面板建店**：管理员面板底部「自定义商店」→「创建」，填 **ID / 名字** 并选**出售类型**（精灵 / 物品 / 两者都卖）、**结算货币**、**经营模式**（普通购买 / 定期领取）与领取周期。⚠ **定期领取模式只能在这里选，建好之后不可改**
- **命令建店**：`/market shop create <id> <名字>` 建的是**默认店**（两者都卖 / 主货币 / 普通购买），之后可用 `type` / `currency` 调整；**模式不能用命令改**
- **绑定 NPC**：看着实体执行 `/market shop bind <id>`，或在管理员面板「选择 NPC」里点身旁 16 格内的实体。一个 NPC 只能服务一家店，一家店可以绑多个 NPC；绑定记的是 UUID，NPC 被删除 / 换新实体后要重新绑定
- ID 用小写字母 / 数字 / `_` / `-`（1~32 位，不能叫 `main`），名字最长 32 字符

## 上架商品

- 打开商店界面（右键 NPC 或 `/market shop open <id>`），点空格子上架 —— 编辑器与 RP 商城**完全同一套**
- 精灵可配物种 / 形态 / 变体 / 等级 / 闪光 / 特性 / 技能 / 个体值 / 携带物等；物品可复制手持那件的全部组件
- 库存留空 = 不限量，填数字 = 限量；**定期领取店的「数量」= 每期每人可领几个**（0 = 不开放，不能设成无限）
- 切换出售类型**不会删除**另一类商品，只是隐藏
- **左键购买、右键编辑**：服主 / 持 `points.shop` 权限的人**右键已有商品**即可直接修改全部字段（精灵规格、价格、库存、冷却等），不用再「下架 → 重新上架」；**左键仍是购买**（与已发布行为一致，空格子左键 = 添加）。领取店没有购买，权限者左键即编辑。编辑窗右上角保留「下架」按钮
- **编辑期间整店暂停购买**：有人打开编辑窗时，这家店对其他玩家的购买按钮立即置灰、点击只响失败音并提示「服主正在编辑这家商店」；关闭编辑窗（或编辑者断开）后自动恢复。服务端同样拦截，伪造购买包也买不了
- **格子悬停详情**：购买店悬停商品格子也会显示完整精灵规格 / 物品词条，最后一行是**完整单价 + 限量库存**（格子里的价格是缩写）；领取店最后一行是可领数量

## 购买冷却

普通购买店可以给玩家设**购买冷却**（单位：小时，0 = 不开），分两层，可以只开一层也可以同时开：

- **整店冷却**：买成任意一格后，这家店对这个人整体上锁
- **商品各自冷却**：每件商品单独计时 —— 买过的那件才锁，其他商品照常买
- 同一格同时受两层影响时**取较长者**（整店保底）；单格还能在编辑窗里再覆盖（留空 = 跟随商店设置，同样取较长者）
- 有冷却的商品**每次只能买 1 件**（即使库存无限），且只在**购买成功后**开始计时 —— 失败 / 背包满 / 余额不足都不触发
- 按服务器时间计算，重启后继续；下架重上（新的一格）后该格自己的冷却清零
- **管理入口**：商店管理 → 管理 → 详情里的「设置冷却」可同时改两层；**重置冷却**按钮清空这家店所有玩家的记录（需二次确认）。命令：`/market shop cooldown <id> <小时>`（整店）、`/market shop itemcooldown <id> <小时>`（商品各自）、`/market shop cooldown <id> reset`（清空记录）
- 老商店不用重建 —— 建店之后随时可以设冷却

## 卡片购物折扣

持有喵·紫电卡 / 喵·金轮卡的玩家在这家店**购买**商品时可以享受价格优惠（默认关闭，折扣率在两张卡的配置界面设置；黑卡优先）：

- **本店可以覆盖**：商店管理 → 管理 → 详情弹窗底部「返回」按钮**左右两侧**各一个输入框（左 = 紫电卡、右 = 金轮卡），填百分比（5 = 优惠 5%）
- **留空 = 跟随卡配置**；填 `0` = 本店不优惠；填 `1~100` = 用本店的比例覆盖
- 折后价格**最低为 1**；服主标成 0 元的免费商品保持免费
- 购买窗会提示本次优惠，成交提示显示原价与折后价
- ⚠ 与「手续费减免」是**两件事**：手续费减免管玩家间交易（上架 / 拍卖 / 求购），购物折扣只管在主 RP 商城与自定义 NPC 商店**买东西**的价格

## 定期领取店

- 玩家点底部「**领取**」一键领走全部，**免费**、**不受 RP 总开关影响**
- **滚动冷却**：从第一次真正领到东西开始计时，满周期刷新；周期可用 `/market shop period <id> <小时>` 改（24 = 每日、168 = 每周、720 = 每月）
- **不叠加**：过期没领的部分直接作废；背包 / 队伍 / PC 装不下时**只交付放得下的部分**，剩余留在店里、本期还能再领
- 点「领取」后物品会从各自的格子飞向屏幕底部中央（物品栏 / 快捷栏位置）一路缩小消失，多格依次错开、同一格多件只飞一个图标 + ×N；**精灵不播动画**，留在店里的部分也不播
- 格子**悬停看完整详情**（精灵含等级 / 形态 / 闪光 / 特性 / 个体值 / 技能 / 携带物，物品显示原版词条），最后一行是可领数量
- 每次领取都会写进交易历史：类型显示「领取」（不是卖出）、价格显示「免费」，进「全部交易历史」和领取者个人历史，不会出现在管理员个人历史里

## 交易记录与搜索

- **每家店看自己的记录**：购买店 / 领取店界面顶部有「查看出售记录 / 查看领取记录」（**只有服主 / 持 `points.shop` 权限的人**看得到），只列当前这家店的成交 / 领取。⚠ 升级前产生的旧记录没有商店标识，不会出现在这个列表里（仍可在全服历史看到）
- **店内搜索**：购买店顶部左侧有搜索框（所有玩家可用），跨全部页搜索当前商店的精灵 / 物品名称；结果分页显示，清空搜索恢复普通分页。⚠ 搜索结果是快照，改动或买走商品后要重新搜索才刷新

## 货币与开关

- 结算货币在**创建时**选；**店里有商品后不能改**，只有空店能 `/market shop currency <id> primary|points`
- **RP 总开关关闭**时，RP 计价的普通店会被拦下（提示「市场管理员未开启 RP」），主货币店不受影响；**领取店免费，不受总开关影响**
- **单店开关独立**：`/market shop disable <id>` 只关这一家 —— 玩家不能开 / 买 / 领，管理员仍可从管理员面板进去编辑；⚠ **不跟随市场总开关**（停市不关 NPC 商店）
- 购买与领取都要求玩家在**绑定 NPC 的 8 格内**，打开界面后走开也不行

## 权限、限制与存档

- 管理全部走 `points.shop` 节点（**不认 OP**）；主 RP 商城完全不受影响；自定义商店**只买不卖**
- 已知限制：管理员面板列表里的 NPC 头像对 Easy NPC 等自定义皮肤只显示**默认模型**（**游戏内 NPC 的外观不受影响**）；旧绑定（无 NPC 元数据）可能显示未知实体；管理员面板绑定只列**附近 16 格**，远处用命令
- 存档：`world/data/cobblemarket_custom_shops.dat`（商店 / 类型 / 商品 / NPC 绑定）、`world/data/cobblemarket_custom_shop_claims.dat`（每玩家每店的领取周期与已领数量）与 `world/data/cobblemarket_custom_shop_cooldowns.dat`（每玩家每店 / 每格的购买冷却）；都是新文件，旧存档没有即视为空

## 闪光播报

买到或领取到**闪光**精灵时全服播报：`[商人名] 恭喜 玩家 购买到了 / 领取到了 ★[精灵名]！` —— 自定义商店的前缀取**进店那个 NPC 的名字**（NPC 没有自定义名时退回店名），主 RP 商城固定显示货币图标 `[Ⓡ 商城]`；精灵名可悬停看大图与完整信息
