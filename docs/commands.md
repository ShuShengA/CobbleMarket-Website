# 命令参考

所有命令都挂在 `/market` 下。

## 玩家命令

| 命令 | 说明 |
|---|---|
| `/market gui` | 打开市场入口界面（等同于按 `K`，或从 Cobblemon Smartphone 应用进入） |

## 管理命令

以下命令需要 **OP 权限**。

| 命令 | 说明 |
|---|---|
| `/market on` | 开启整个市场 |
| `/market off` | 关闭整个市场（紧急总开关，关市期间所有买卖/拍卖/求购操作被拦截） |
| `/market ban <玩家> [时长] [理由]` | 封禁玩家交易 |
| `/market unban <玩家>` | 解除封禁 |
| `/market banlist` | 列出当前生效的封禁 |
| `/market card give <玩家> [卡种]` | 发放卡片凭证 |
| `/market card revoke <玩家> [卡种]` | 收回卡片凭证 |
| `/market card list` | 列出已发放的卡片 |
| `/market loan clear <玩家>` | 撤销某玩家的坏账 |
| `/market reload` | 重载配置文件（货币相关配置仍需重启） |

### 参数说明

**封禁时长** —— 格式为「数字 + 单位」：

| 单位 | 含义 | 示例 |
|---|---|---|
| `d` | 天 | `7d` |
| `h` | 小时 | `12h` |
| `m` | 分钟 | `30m` |

- **省略时长 = 永久封禁**
- 理由可选，写在时长之后，可含空格
- 玩家名支持联想：输入前缀即可点选（覆盖该存档所有登录过的玩家，含离线玩家）

例：`/market ban Steve 7d 恶意抬价`

**卡片卡种** —— `purple`（喵·紫金卡，缺省）或 `black`（喵·黑金卡）：

```
/market card give Steve black
/market card revoke Steve
```

## 权限

管理命令需要 **OP 权限**。其中：

- **关市/开市**（`/market on`、`/market off`）与 **服务器配置** 也可以在市场入口的管理员面板里操作，不必敲命令
- **撤销坏账**（`/market loan clear`）只限 OP，不影响其他管理职能
- 关市期间 OP 仍可进入管理员面板执行下架、黑名单等清理操作

## 对应的界面入口

大部分命令都有等价的界面操作，日常管理用界面更方便：

| 功能 | 界面入口 |
|---|---|
| 开关市场 | 管理员面板底部 |
| 封禁管理 | 管理员面板 → 封禁管理 |
| 黑名单/价格限制 | 管理员面板 |
| 强制下架 | 管理员面板 → 所有拍卖/所有上架/所有求购 |
| 服务器配置 | 管理员面板底部 |
| 卡片管理 | 喵喵银行 → 卡片管理 |
| 全服借贷流水/撤销坏账 | 管理员面板 → 全服借贷流水 |

详见 [功能特色](/features)。
