# 封禁管理（服主向）

本文档说明「封禁」到底限制什么、不影响什么，以及它和金融冻结的关系 —— **封人之前建议先看这一页**。

## 一、怎么封

| 方式 | 操作 |
|---|---|
| 管理员面板 | 「封禁管理」页签：填玩家名、时长、理由 → 确认；列表中能看到谁封的、还剩多久，可随时解封 |
| 命令 | `/market ban <玩家> [时长] [理由]` · `/market unban <玩家>` · `/market banlist` |

- **时长**：`30m`（分钟）/ `12h`（小时）/ `7d`（天），可叠加写成 `1d12h`；**不写时长 = 永久封禁**
- **权限**：需要**封禁**权限节点（服主恒真；体系见[权限节点](/permission)）

## 二、封禁限制什么

一句话：**所有「从市场里花钱」和「把手里的东西卖出去」的操作**。

- **买入精灵**
- **购买物品**
- **上架出售精灵**（从队伍或电脑）
- **上架出售物品**
- **发起拍卖**（精灵 / 物品）
- **拍卖出价**
- **发布求购单**（精灵 / 物品）
- **交付**（用自己的东西去满足别人的求购单，精灵 / 物品）
- **领取待交付**（这一步要付钱取货，所以算交易）

## 三、封禁不影响什么

封禁**不没收已有资产**，也不接管其他系统：

- **取回自己的东西**：取消挂单、领取退货（精灵 / 物品）、领取待领余额、**拒绝交付**（把东西退回去）
- **喵喵银行**：存款 / 取款 / 借款 / 还款照常 —— 银行有自己的一套限制（额度、逾期、坏账），**不看封禁**
- **卡片**：申请与使用照常

⚠ 所以准确的说法是：**封禁 = 掐掉市场的交易入口**，而不是"冻结这个玩家"。

## 四、它和「金融冻结」是同一张名单

- 贷款**逾期满 14 天**时，金融系统会**自动**把该玩家加进这张封禁名单，理由显示为「金融冻结」
- 逾期降到 14 天以下（还款或自动划扣之后）会**自动解封**，并给玩家一条提示
- ⚠ **坏账不会自动解、也不会自动补** —— 交给服主裁量（`/market loan clear` 处理坏账）
- ⚠ 服主**手动解封**同样放行市场交易，金融系统不会在下次登录时又把它冻上
- ⇒ 在封禁列表里看到自己没封过的人，多半是**逾期自动冻结**，先看理由那一栏

## 五、被封的玩家会看到什么

- **界面照常能打开**（没有"你已被封禁"的常驻提示）
- 只有**点下被限制的操作**时才被服务端拒绝，并收到一条红字提示：**剩余时长 + 封禁理由**
- ⇒ 目前玩家只能"点到才知道"，没法提前看到自己的封禁状态
