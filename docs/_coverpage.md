# CobbleMarket

> 面向 Cobblemon 服务器的玩家交易市场模组

- 精灵市场 / 物品市场 / 拍卖场 / 求购单
- 可选喵喵银行金融系统：信用借贷、存款与卡片凭证
- 四种货币自动适配，Fabric 与 NeoForge 双平台
- 交易历史、CSV 账本与数据备份
